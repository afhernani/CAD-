**CAD+ | Motor de Diseño Asistido por Computadora (CAD) 2D** *C++20, SFML, CMake, Pixi | Arquitectura MVC*

- Diseñé y desarrollé desde cero un motor geométrico 2D en **C++20**, aplicando el patrón de arquitectura MVC para separar estrictamente la lógica matemática (Engine), el modelo de datos (Document) y el renderizado (View).
- Implementé algoritmos matemáticos avanzados para el parseo de sistemas de coordenadas absolutas, relativas y polares, emulando la precisión de herramientas líderes como AutoCAD.
- Desarrollé un sistema de *Object Snaps* (forzado magnético) calculando intersecciones y distancias en tiempo real para garantizar precisión milimétrica en la inyección de coordenadas.
- Construí un pipeline de persistencia de datos (serialización) para el guardado y carga de documentos geométricos complejos.
- Configuré un entorno de desarrollo moderno y reproducible utilizando **CMake** para el build system y **Pixi** para la gestión de dependencias y entornos.

**CAD+ | Motor Gráfico 2D y Herramientas de Precisión** *C++20, SFML, Matemáticas Vectoriales, Gestión de Estado*

- Programé un motor 2D personalizado en **C++20 y SFML**, gestionando el bucle de renderizado, la cámara virtual y la conversión de coordenadas de Mundo a Pantalla.
- Implementé controles de cámara fluidos mediante transformaciones afines (Zoom centrado en el cursor y *Pan* con arrastre de ratón), procesando entradas de hardware de baja latencia.
- Desarrollé un parser de línea de comandos interactivo con gestión de estado, historial y comandos contextuales, optimizando la interacción usuario-motor (UI/UX para herramientas técnicas).
- Aplicé matemáticas vectoriales y trigonométricas para la generación procedural de geometrías (Círculos, Polilíneas) y cálculos de proximidad (snapping magnético).
- *Proyecto paralelo:* Este desarrollo de bajo nivel complementa mi formación actual en **Unity (C#)**, aportando una comprensión profunda de los motores gráficos comerciales.
